# Energy Insights – My Energy Profile

## Description

**My EnergyLens** is a web-based interactive project focused on visualizing and contextualizing energy-related data.  
This repository contains the technical foundation, UI structure, and setup for the application.

Conceptual descriptions, ideas, and planned content are documented separately and are **not part of this README**.

---

## Tech Stack

### Frontend
- **HTML5** – semantic structure
- **CSS3** – layout, responsive design, and styling
- **JavaScript (Vanilla)** – interactivity and data handling

### Data Visualization (planned)
- **D3.js** or similar JavaScript visualization libraries

### Data Sources (planned integration)
- External open datasets (e.g. OWID, IEA, World Bank, EIA)

> Note: Data integration is not yet implemented and will be added in a later development phase.
